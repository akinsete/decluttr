# Bundled fonts

## Plus Jakarta Sans (UI)

TTF files in this folder are from **[Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)** (Google Fonts), licensed under the **SIL Open Font License 1.1**.

They are bundled so `google_fonts` can resolve **Plus Jakarta Sans** when `allowRuntimeFetching` is **false** (see `lib/main.dart` and `test/flutter_test_config.dart`). File names match Google Fonts conventions (e.g. `PlusJakartaSans-Regular.ttf`, `PlusJakartaSans-SemiBold.ttf`).
